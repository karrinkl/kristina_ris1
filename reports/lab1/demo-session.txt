=== Демонстрация возможностей C# (типы, boxing, nullable) ===
1. Типы-значения (struct) и ссылочные типы (class)
   struct: a = 1 кг, b = 5 кг — b получила копию, a не изменилась
   class:  a = 5 кг, b = 5 кг — обе переменные указывают на один объект
   ReferenceEquals(classA, classB) = True
2. Boxing и unboxing
   переменная = 50, упакованная копия = 42, тип объекта: Int32
   (long)boxed -> InvalidCastException: распаковать можно только в исходный тип int
   Обобщённые коллекции (List<decimal>, Dictionary<int, Candy>) хранят значения без упаковки.
3. Nullable value types и nullable reference types
   int? shelfLifeDays = null: HasValue = False, shelfLifeDays ?? 180 = 180
   после присваивания 90: HasValue = True, Value = 90
   string? customer = null: customer?.Length ?? 0 = 0
   после присваивания компилятор знает, что значение не null: Length = 18
4. Pattern matching и switch-выражение
   положительное целое число 42
   decimal 12,5 — подходит для денежных сумм и масс
