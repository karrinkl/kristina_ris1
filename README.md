# Лабораторная работа № 1. Основы C# и платформы .NET

**Вариант:** учёт продажи конфет кондитерской фабрикой.

Консольное приложение на C# для кондитерской фабрики «Сладкий край» (вымышленной): ведёт ассортимент конфет
и остатки на складе, оформляет продажи с проверкой остатка, хранит историю продаж с ценой на момент продажи,
считает выручку и показывает самые продаваемые конфеты. На его примере продемонстрированы темы ЛР № 1:
архитектура .NET, система типов, свойства, синтаксические возможности C#, коллекции, делегаты и события,
`IDisposable`/`using`, исключения и проверка ввода.

Отчёт по работе: [`reports/lab1/REPORT.md`](reports/lab1/REPORT.md).

## Требования к окружению

* **.NET SDK 8.0** (любой выпуск 8.0.x). Приложение и тесты нацелены на `net8.0`, поэтому для запуска нужна
  среда выполнения .NET 8. Если установлен только SDK 9/10, установите дополнительно SDK или runtime 8.0.
* ОС: Linux (проверено на Ubuntu 24.04) или Windows 10/11. Bash, GNU-утилиты и глобальные библиотеки не нужны.
* Интернет нужен один раз — для `dotnet restore` тестового проекта (пакеты xUnit с nuget.org). Само приложение
  внешних пакетов не использует. Без интернета восстановление пройдёт только при заранее заполненном
  кэше NuGet (`~/.nuget/packages` в Linux, `%USERPROFILE%\.nuget\packages` в Windows) или локальном источнике пакетов.

### Установка .NET 8 SDK

**Linux (Ubuntu 22.04/24.04):**

```bash
sudo apt-get update
sudo apt-get install -y dotnet-sdk-8.0
dotnet --list-sdks          # должна быть строка 8.0.xxx
```

Для других дистрибутивов или без прав администратора — официальный скрипт
(<https://learn.microsoft.com/dotnet/core/tools/dotnet-install-script>):

```bash
curl -sSL https://dot.net/v1/dotnet-install.sh -o dotnet-install.sh
bash dotnet-install.sh --channel 8.0
export PATH="$HOME/.dotnet:$PATH"
dotnet --list-sdks
```

**Windows (PowerShell):**

```powershell
winget install Microsoft.DotNet.SDK.8
# после установки откройте новое окно PowerShell
dotnet --list-sdks          # должна быть строка 8.0.xxx
```

Либо скачайте установщик .NET 8 SDK со страницы <https://dotnet.microsoft.com/download/dotnet/8.0>.

## Сборка, запуск и тесты

Все команды выполняются **из корня репозитория** (каталог `kristina_ris1`).

### Linux (Bash)

```bash
dotnet --info
dotnet restore lab1/CandySales.sln
dotnet build lab1/CandySales.sln
dotnet run --project lab1/src/CandySales/CandySales.csproj
dotnet test lab1/CandySales.sln
```

### Windows (PowerShell)

```powershell
dotnet --info
dotnet restore lab1\CandySales.sln
dotnet build lab1\CandySales.sln
dotnet run --project lab1\src\CandySales\CandySales.csproj
dotnet test lab1\CandySales.sln
```

Проверочная сборка в режиме Release (так собирает CI; любое предупреждение компилятора считается ошибкой):

```bash
dotnet build lab1/CandySales.sln --configuration Release
dotnet test lab1/CandySales.sln --configuration Release --no-build
```

## Функции меню

| № | Пункт | Что делает |
|---|---|---|
| 1 | Показать весь ассортимент | Таблица: код, название, категория, цена за кг, остаток, состояние склада |
| 2 | Добавить новый вид конфет | Название (уникальное), категория, цена (> 0, до копеек), начальный остаток (≥ 0, до грамма) |
| 3 | Изменить вид конфет | Новое название, категория, цена; Enter оставляет значение. История продаж не меняется |
| 4 | Принять на склад новую партию | Увеличивает остаток на массу произведённой партии |
| 5 | Удалить вид конфет | Только если по нему нет продаж (иначе нарушится история) |
| 6 | Найти конфеты по названию | Поиск по части названия без учёта регистра |
| 7 | Отфильтровать ассортимент | По категории, диапазону цен, наличию, «заканчивается» (< 20 кг) |
| 8 | Отсортировать ассортимент | По названию, цене или остатку; по возрастанию или убыванию |
| 9 | Оформить продажу | Выбор конфет, масса в кг, покупатель; проверка остатка, расчёт стоимости, подтверждение, списание со склада |
| 10 | Показать все продажи | История продаж с ценой на момент продажи и общая выручка |
| 11 | Найти продажи | По дате, за период, по названию конфет, по покупателю |
| 12 | Рассчитать выручку | За выбранный период, за сегодня, за 7 дней, за всё время |
| 13 | Самые продаваемые конфеты | Рейтинг по проданной массе: кг, число продаж, выручка |
| 14 | Демонстрация возможностей C# | Типы-значения и ссылочные типы, boxing/unboxing, nullable, pattern matching |
| 0 | Выход | Завершение работы (также корректно обрабатываются Ctrl+C и конец ввода Ctrl+D / Ctrl+Z) |

Форматы ввода: дробные числа — через запятую или точку (`12,5` и `12.5`), даты — `ДД.ММ.ГГГГ`,
подтверждение — `д`/`н` (также `да`/`нет`, `y`/`n`). При ошибке приложение показывает причину и повторяет запрос.

## Демонстрационные данные

При каждом запуске создаётся ассортимент из 9 видов конфет (шоколадные, карамель, ириски, мармелад, драже,
помадные, суфле) и 9 продаж за последние 6 дней относительно текущей даты. Данные вымышленные. Специально
предусмотрены:

* «Мятная карамель» с остатком 17 кг — состояние «заканчивается», при продаже появляется предупреждение;
* «Суфле ванильное» с нулевым остатком — продажа отклоняется, пока не принята новая партия;
* «Арахис в шоколадной глазури» без продаж — его можно удалить, в отличие от остальных позиций.

## Журнал продаж

Состояние ассортимента хранится в памяти и при перезапуске восстанавливается из демонстрационных данных
(база данных в ЛР № 1 не требуется). Каждая **новая** продажа, оформленная пользователем, дописывается в журнал
`journal/sales-journal.csv` рядом с исполняемым файлом (при `dotnet run` в отладочной конфигурации —
`lab1/src/CandySales/bin/Debug/net8.0/journal/sales-journal.csv`; полный путь печатается при запуске).

Формат: UTF-8 с BOM (корректно открывается в Excel), разделитель `;`, первая строка — заголовок
`Id;SoldAt;CandyId;CandyName;QuantityKg;PricePerKg;Total;CustomerName`, числа с точкой, дата `yyyy-MM-dd HH:mm:ss`.
Журнал только дописывается и при запуске не читается. Если файл открыть не удалось (нет прав, диск недоступен),
приложение предупреждает об этом и работает без журнала.

## Непрерывная интеграция

Workflow [`.github/workflows/lab1-ci.yml`](.github/workflows/lab1-ci.yml) запускается при `push` и `pull_request`,
на `ubuntu-latest` и `windows-latest` устанавливает .NET 8 SDK, восстанавливает зависимости, собирает решение
в Release (предупреждения = ошибки), запускает тесты и выполняет короткий запуск приложения. Любая ошибка
останавливает проверку с неуспешным статусом. Результаты: вкладка **Actions** репозитория.

## Известные ограничения

* Данные (кроме журнала продаж) не сохраняются между запусками — так задумано для учебной работы.
* Одна продажа — один вид конфет; скидки, НДС и возвраты не учитываются.
* Цена хранится в рублях с точностью до копейки, масса — в килограммах с точностью до грамма; максимальная цена —
  100 000 руб./кг, максимальная масса — 1 000 000 кг.
* Выбор режима UTF-16 для консоли Windows в автоматической проверке не проверяется: CI запускает приложение с
  перенаправленным вводом-выводом. Интерактивную работу в Windows нужно проверить вручную (см. отчёт, раздел 12).
* При первом запуске в Windows-терминале со старым растровым шрифтом символы «─», «×», «…» могут отображаться
  некорректно — используйте Windows Terminal или шрифт Consolas/Cascadia Mono.
